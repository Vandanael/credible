# Credible?

A minimalist quote game.  
Can you tell real quotes from fake ones?

## Why
Credible? is designed as a lightweight brain challenge focused on intuition and critical thinking.
No accounts, no tracking, just quick decisions.

## How it works
- 5 quotes per challenge
- Instant feedback
- One-click answers
- No sign-up, no data collection

## Tech stack
- React + Vite
- Tailwind CSS + shadcn/ui
- Deployed on GitHub Pages
